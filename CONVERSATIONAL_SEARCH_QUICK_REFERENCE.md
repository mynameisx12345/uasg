# 🔍 Quick Reference: Conversational NLP Search

## Try These Queries!

### Show All Files by Category

| Query | What It Does |
|-------|-------------|
| `show me all resolutions` | Shows all resolution files |
| `show me all memorandums` | Shows all memorandum files |
| `show me all amendments` | Shows all amendment files |
| `show me all ordinances` | Shows all ordinance files |
| `show me all contracts` | Shows all contract files |
| `show me all reports` | Shows all report files |
| `show me all minutes` | Shows all meeting minutes |
| `show me all letters` | Shows all letter files |

### Search Within Categories

| Query | What It Does |
|-------|-------------|
| `find resolutions about budget` | Searches "budget" in resolutions |
| `find memorandums containing policy` | Searches "policy" in memorandums |
| `find amendments with revised` | Searches "revised" in amendments |
| `show me contracts about procurement` | Searches "procurement" in contracts |

### Alternative Phrasings (All Work!)

- "Can you show me all resolutions?"
- "Could you show me all resolutions?"
- "Please show me all resolutions?"
- "Display all resolutions"
- "List all resolutions"
- "Get me all resolutions"
- "I want to see all resolutions"
- "I need all resolutions"

## Recognized Categories

✅ **resolution** (resolutions, resolusyon)
✅ **memorandum** (memorandums, memo, memos)
✅ **amendment** (amendments, revised)
✅ **ordinance** (ordinances)
✅ **contract** (contracts, agreement, agreements)
✅ **report** (reports, reporting)
✅ **minutes** (meeting minutes, meeting notes)
✅ **letter** (letters, correspondence)
✅ **proposal** (proposals)
✅ **policy** (policies)

## Tips

✅ **DO**: Use natural language questions
✅ **DO**: Mention the category clearly
✅ **DO**: Keep queries simple and clear

❌ **DON'T**: Use overly complex sentences
❌ **DON'T**: Mix multiple categories in one query
❌ **DON'T**: Use category dropdown when using conversational search

## Traditional Search Still Works!

You can still search the old way:
1. Enter a keyword (e.g., "budget")
2. Select category from dropdown (e.g., "Resolution")
3. Click Search

## Response Messages

You'll see friendly messages like:
- ✅ "Found 15 Resolution file(s)"
- ✅ "Found 8 Memorandum file(s) matching 'budget'"
- ⚠️ "Found 0 file(s)"
